# Report format

Lead with the answer. The author should know within five seconds whether the document can go out.

## 1. Verdict

One line: the verdict, the main reason, and coverage.

- **Clear to send**: no High or Medium issues; any Low issues are optional polish.
- **Fix before sending**: one or more Medium issues, or High issues that have a straightforward fix given below.
- **Do not send yet**: a High-risk claim is wrong, unsupported or unverifiable and the document relies on it; or there is a legal, health, safety or reputational risk that needs a human decision.

Example: "**Fix before sending**: the headline market size is outdated (newer 2025 figure available) and two totals don't add up. 38 of 38 claims checked."

## 2. Priority fixes

Most serious first. For each:

- **Where**: page / section / slide / paragraph.
- **What the document says**: quoted.
- **What's wrong**: status and one-line explanation.
- **Evidence**: source with date and link, or the recalculation.
- **Replace with**: exact new wording, ready to paste.

Keep this to the issues that matter; routine confirmations go in the ledger.

## 3. Claim ledger

| # | Where | Claim (as written) | Type | Risk | Status | Source (publisher, title, date) | Link | Note |
|---|---|---|---|---|---|---|---|---|

- One row per claim, in order of appearance.
- The note says what the source actually states when it differs, or the corrected calculation.
- Deliver the ledger as a table in the reply; for long documents also as a spreadsheet file.

## 4. Corrected version

- Same format as the original where possible: Word stays Word (tracked changes or comments preferred), slides stay slides, web copy stays text.
- Apply every fix from section 2. Add citations in the style the document already uses; if it has none, add short footnotes or a Sources list at the end.
- Do not rewrite style or structure beyond what accuracy requires, unless asked.

## 5. For the author to confirm

- The author's own figures, with any inconsistencies found.
- Every `[needs source]` placeholder left in the corrected version.
- Anything flagged for human judgment (reputation, legal, health, safety).

## Claim check (single claim) format

For one statement: the verdict (True / Partly true / False / Outdated / Unverified), what the trusted sources say with dates and links, where the claim most likely came from, and a corrected sentence ready to use.
